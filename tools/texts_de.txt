[lines help_text]
1 Hilfe zu GeoWorks 1.x Test
0 Das Programm liest aus, auf welchem Rechner oder Emulator GeoWorks läuft,
0 und führt vor, was mit dem SDK pcgeos-1-sdk-v2 unter GeoWorks 1 möglich ist.
2
1 Seiten
3 1 Übersicht – das Wichtigste auf einen Blick
3 2 System – Prozessor, BIOS, Emulator, Schnittstellen, DOS
3 3 Speicher – konventionell, CMOS, XMS, EMS, GEOS-Speichertreiber
3 4 Bildschirm – GEOS-Treiber, VESA-BIOS, Auflösung, Farbtiefe
3 5 GEOS – Version, Verzeichnis, Oberfläche, Geräte aus GEOS.INI
3 6 Leistung – Rechen-, Grafik-, Speicher- und Dateitempo
3 7 Grafik – Farben, RGB, Formen, Muster, Schriften, Bitmaps
3 8 Eingabe – Tastencodes, Mauskoordinaten, Malfläche
3 9 Schriften – alle Schriftdateien im Ordner FONT, jede mit einem Muster
3 0 Klang – Töne, Tonleiter, Lied und Akkord über den PC-Lautsprecher
2
1 Tasten
3 1 bis 9, 0: Seite wählen    N / Leertaste: nächste Seite    P: vorige Seite
3 Pfeiltasten oder + / −: rollen    M: neu messen
3 S: Bericht speichern    K: Bericht kopieren    H oder ?: Hilfe    I: Info
3 Esc: zurück zur Übersicht
2
1 Menü Datei
3 Bericht speichern – schreibt DOCUMENT\GWTEST.TXT (reiner ASCII-Text)
3 In Zwischenablage kopieren – zum Einfügen in GeoWrite oder den Notizblock
3 Drucken … – der ganze Bericht über den GeoWorks-Druckdialog
3 Neu messen – Geschwindigkeit, Grafik, Speicher und Datei neu messen
2
1 Hinweise
0 Die Werte stammen aus BIOS, DOS, VESA-BIOS, XMS-/EMS-Treiber und GEOS.INI.
0 Emulatoren werden an ihrer Kennung im BIOS erkannt. Der Geschwindigkeits-
0 index vergleicht mit einem IBM PC/XT (8088, 4,77 MHz) = 1,0.
